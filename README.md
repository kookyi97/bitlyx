# Bitlyx Academy

Plataforma Interactiva de Aprendizaje Tecnologico

Bitlyx Academy es un sistema web educativo desarrollado con Laravel y MySQL que permite a los usuarios acceder a modulos de aprendizaje, completar lecciones interactivas, evaluar sus conocimientos mediante quizzes y hacer seguimiento de su progreso con un sistema de puntos XP y ranking.
